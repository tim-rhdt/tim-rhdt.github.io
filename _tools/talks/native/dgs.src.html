Basic Terms

Definition.

An operation is a relation \(\omega \subseteq I_1 \times \ldots \times I_k \times O \in \{P, L, Q, C\}^{k+1} \quad (k \in \mathbb{N})\).

For \(k = 0\), we call \(\omega \in \{P, L, Q, C\}\) a free operation.

An operation \(\omega\) is called algebraic if it is the set of all \((i_1, \ldots, i_k, o)\) which satisfy a system of polynomial

equations and which respect certain non-degeneracy conditions.

Moreover, we write

\(\omega(i_1, \ldots, i_k) := \{o \in O \mid (i_1, \ldots, i_k, o) \in \omega\}\).

Example.

Join: \(\{(p, q, l) \in P \times P \times L \mid p^T l = 0\) and \(q^T l = 0\}\)

Join: \(\{(p, q, l) \in P \times P \times L \mid p^T l = 0\), \(q^T l = 0\) and \(p \neq q\}\)

IntersectionConicLine: \(\{(c, l, p) \in Q \times L \times P \mid p\) lies on \(c\), \(l^T p = 0\) and \(c\) non-degenerate\(\}\)

Basic Terms

Definition.

A (geometric) construction consists of

1.

a sequence \(O_{1-m}, \ldots, O_0, O_1, \ldots, O_n \in \{P, L, Q, C\}\) of geometric types, and

2.

a sequence \(\omega_{1-m}, \ldots, \omega_n\) of corresponding operations where \(\omega_{1-m}, \ldots, \omega_0\) are all free operations

and \(\omega_1, \ldots, \omega_n\) only use free or already constructed objects as input.

A (geometric) instance of a geometric construction is an element

\(o = (o_{1-m}, \ldots, o_n) \in O_{1-m} \times \ldots \times O_n\)

such that the corresponding subtuples of \(o\) are contained in each \(\omega_k\).

The set of all instances of a construction is called the configuration space of the construction.

Fundamental Properties

Consistency.

In every instance of a construction that is shown by

the DGP, the geometric objects have the type and

fulfill the relations determined by the construction.

Determinism.

In a DGP, the same movements from the same

starting instances always yield the same motions

of dependent elements.

Conservatism.

In a DGP, the ending instance is completely

determined by the starting instance and the

ending positions of the free elements.

Continuity.

If the free elements of a construction move

continuously, the induced paths of dependent

elements are continuous as well.

Our Framework

Definition.

A map \(\mu : [0,1] \to T \in \{P, L, Q, C\}\) is called a movement if there exists an open neighborhood

\([0,1] \subset U \subseteq \mathbb{C}\) and a holomorphic map \(\varphi : U \to T\) with \(\varphi_{|_{[0,1]}} = \mu\).

Given a construction with \(m\) free objects and a starting instance \(o\). Let

\(M = \{\mu : [0,1] \to O_{1-m} \times \ldots \times O_0 \mid \forall j : \mu_j\) is movement with \(\mu_j(0) = o_j\}\).

Moreover, let \(N = \{\nu : [0,1] \to O_1 \times \ldots \times O_n\}\).

A dynamic geometry system (DGS) is a map \(M \to N\) such that \(\forall t \in [0,1]\), \((\mu(t), \nu(t))\) is an instance of

the underlying geometric construction.

Observation.

This definition of a DGS automatically ensures consistency and determinism

(since \(\nu\) decomposes into functions).

Conservatism vs. Continuity

Example.

Consider a DGS with the following operations:

FreePoint, Join(\(\cdot\),\(\cdot\)), Meet(\(\cdot\),\(\cdot\)), AngularBisector(\(\cdot\),\(\cdot\))

which is captured by

FreePoint, Join(\(\cdot\),\(\cdot\)), Meet(\(\cdot\),\(\cdot\)), CircleMidRadius(\(\cdot\),\(\cdot\)), IntersectionCircleLine(\(\cdot\),\(\cdot\)),

IntersectionCircleCircle(\(\cdot\),\(\cdot\)).

\(\Rightarrow\) Conservatism and continuity are mutually exclusive if sufficiently complex operations are admissible.

\(\Rightarrow\) It is “likely” that not the whole configuration space is reachable in a conservative DGP.

Reachability

Reachability Problem in Dynamic Geometry.

Given two instances of an algebraic construction, is it possible to move continuously from one to the other

using only paths of a certain type?

Theorem (Kortenkamp, Richter-Gebert).

The reachability problem is

PSPACE-hard in general,

NP-hard if FreePoint, Join(\(\cdot\),\(\cdot\)), Meet(\(\cdot\),\(\cdot\)), AngularBisector(\(\cdot\),\(\cdot\)) are the admissible operations,

undecidable if “algebraic” is dropped.

Continuous DG Systems

Continuity makes theorems possible!

A theorem in DG is an algebraic property that holds on an open neighborhood of an instance.

Theorem (Kortenkamp, Orendt, Richter-Gebert).

There exists a continuous DGS for every algebraic construction

(if the starting instance satisfies certain non-degeneracy constraints).

Key ideas.

Complex detours: Use the neighborhood of a movement to avoid singularities.

One then needs to show that the limit of smaller detours converging to \([0,1]\) do not induce discontinuities

in the limit case.

In practice: Path tracing problem
