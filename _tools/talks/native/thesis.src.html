Appendix

Some Facts

Carathéodory’s theorem.

Let \(\displaystyle f \colon U \rightarrow \mathbb{E}\) be a biholomorphic map from a region \(\displaystyle U\) to the unit disk. Then, \(\displaystyle f\) can

be extended to a homeomorphism \(\displaystyle \bar{U} \rightarrow \bar{E}\) if and only if the boundary \(\displaystyle \partial U\) is a closed

Jordan curve.

In this case, it holds that \(\displaystyle f(\partial U) = \partial \mathbb{E}\).

Möbius Transformations.

Every conformal automorphism of the unit disk is a

Möbius transformation.

So, the Riemann mapping theorem can be used as a

tool to talk about “generalized Möbius transformations”.
