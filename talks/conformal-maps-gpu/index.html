Appendix

Some Facts

Möbius Transformations.

Every conformal automorphism of the unit disk is a Möbius transformation.

So, the Riemann mapping theorem can be used as a tool to talk about “generalized Möbius transformations”.

Carathéodory’s theorem.

Let … be a biholomorphic map from a region … to the unit disk. Then, … can be extended to a homeomorphism … if and only if the boundary … is a closed Jordan curve.
